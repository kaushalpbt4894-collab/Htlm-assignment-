# HTML & CSS Assignment

A comprehensive web project showcasing core HTML5 and CSS3 fundamentals and practical projects.

## Included Pages & Projects
- `index.html`: Main home page covering core HTML/CSS concepts summary [cite: 1, 2]
- `about.html`: About page demonstrating semantic/non-semantic elements and links [cite: 1, 2]
- `registration.html`: Registration form showcasing HTML form controls [cite: 1, 2]
- `contact.html`: Contact page with message input form [cite: 1]
- `resume.html`: Resume structure using HTML tables [cite: 1, 2]
- `portfolio.html`: Profile cards using Flexbox layout [cite: 1]
- `styles/style.css`: Stylesheet containing custom variables, reset rules, positioning, Flexbox, and responsive media queries [cite: 1]
